                <h2>📖 Historia y Evolución del PRP</h2>

                <p>El Plasma Rico en Plaquetas tiene sus orígenes en la medicina transfusional de los años 70, cuando los hematólogos comenzaron a estudiar el rol de las plaquetas en los procesos de coagulación y curación.</p>

                <h3>🕐 Línea del Tiempo</h3>

                <div class="table-container">

                <table>

                    <tr><th>Año</th><th>Hito</th><th>Significado</th></tr>

                    <tr><td>1970s</td><td>Concentrados plaquetarios</td><td>Uso en transfusiones y oncología</td></tr>

                    <tr><td>1987</td><td>Primer PRP documentado</td><td>Ferrari et al. — cirugía cardíaca</td></tr>

                    <tr><td>1998</td><td>PRP en cirugía oral</td><td>Marx et al. — regeneración ósea</td></tr>

                    <tr><td>2000s</td><td>Expansión a ortopedia</td><td>Tratamiento de tendones y articulaciones</td></tr>

                    <tr><td>2006</td><td>PRP en medicina estética</td><td>Aplicaciones faciales y capilares</td></tr>

                    <tr><td>2015</td><td>PRF y variantes</td><td>3ª generación sin anticoagulantes</td></tr>

                    <tr><td>2019</td><td>PRP con biorreactor</td><td>4ª generación — activación térmica</td></tr>

                    <tr><td>2022+</td><td>PRP nanotecnológico</td><td>5ª generación — exosomas + IA</td></tr>

                </table>

                </div>

                <h3>🧬 ¿Qué es exactamente el PRP?</h3>

                <p>El Plasma Rico en Plaquetas es una fracción autóloga de sangre (del propio paciente) con una concentración plaquetaria superior a la normal. Una muestra de sangre normal contiene entre <strong>150.000 y 400.000 plaquetas por microlitro</strong>, mientras que un PRP de calidad debe tener <strong>al menos 1.000.000 de plaquetas por microlitro</strong>, es decir, 3-5 veces la concentración normal.</p>

                <div class="info-box blue">

                    🔬 <span><strong>Dato científico:</strong> El término "PRP" fue acuñado por Everts et al. en 2006 y estableció los criterios mínimos de concentración plaquetaria que aún se usan como referencia en investigación clínica.</span>

                </div>

                <h3>🌍 Evolución en medicina estética</h3>

                <p>La introducción del PRP en medicina estética transformó el paradigma del rejuvenecimiento. Por primera vez se disponía de un tratamiento completamente autólogo (sin productos externos), biocompatible y con evidencia científica sólida para:</p>

                <ul>

                    <li>Estimular la producción de colágeno y elastina</li>

                    <li>Mejorar la textura y luminosidad de la piel</li>

                    <li>Tratar la alopecia androgenética</li>

                    <li>Regenerar cicatrices y manchas</li>

                    <li>Mejorar la calidad general de la piel</li>

                </ul>

                <div class="info-box gold">

                    💡 <span><strong>Reflexión:</strong> La evolución del PRP nos muestra que cada generación no descarta la anterior, sino que la mejora. Conocer la historia te permite entender POR QUÉ funciona el PRP 5G, no solo CÓMO aplicarlo.</span>

                </div>

                <h2>🩸 Las Plaquetas: Protagonistas del PRP</h2>

                <p>Las plaquetas (trombocitos) son fragmentos celulares anucleados derivados de los megacariocitos en la médula ósea. Con un diámetro de 2-4 micrómetros y una vida media de 7-10 días, son las células más pequeñas de la sangre pero con un impacto regenerativo extraordinario.</p>

                <h3>Estructura interna de la plaqueta</h3>

                <div class="table-container">

                <table>

                    <tr><th>Componente</th><th>Función en PRP</th></tr>

                    <tr><td>Gránulos Alpha (α)</td><td>Contienen factores de crecimiento: PDGF, TGF-β, VEGF, IGF, EGF</td></tr>

                    <tr><td>Gránulos Dense (δ)</td><td>ADP, serotonina, calcio — activan otras plaquetas</td></tr>

                    <tr><td>Gránulos Lambda (λ)</td><td>Enzimas lisosomales para remodelación tisular</td></tr>

                    <tr><td>Membrana fosfolipídica</td><td>Base para cascada de coagulación y señalización</td></tr>

                    <tr><td>Glucoproteínas de superficie</td><td>Adhesión, agregación e interacción celular</td></tr>

                </table>

                </div>

                <h3>Activación plaquetaria</h3>

                <p>La activación es el proceso clave que libera todos los factores de crecimiento contenidos en los gránulos. En el PRP 5G, este proceso se optimiza mediante:</p>

                <ul>

                    <li><strong>Cloruro de calcio (CaCl2):</strong> Activador fisiológico más usado</li>

                    <li><strong>Trombina autóloga:</strong> Más fisiológica pero más compleja</li>

                    <li><strong>Temperatura controlada (biorreactor):</strong> Exclusiva del PRP 4G-5G</li>

                    <li><strong>Colágeno nativo:</strong> Activación más gradual y sostenida</li>

                </ul>

                <div class="info-box red">

                    ⚠️ <span><strong>IMPORTANTE:</strong> Una plaqueta mal activada libera solo el 30-40% de sus factores de crecimiento. El protocolo de activación correcto es lo que diferencia un PRP mediocre de uno excepcional.</span>

                </div>

    function selectOption(el, qName, val) {

        document.querySelectorAll[onclick*="'${qName}'"]).forEach(o => o.classList.remove('selected'));

        el.classList.add('selected');

        quizAnswers[qName] = val;

        el.querySelector('input').checked = true;

    }

    function checkQuiz(quizId, correctAnswers) {

        const questions = {

            'quiz1': ['q1','q2','q3','q4','q5'],

            'quiz2': ['q2-1','q2-2','q2-3','q2-4'],

            'quiz3': ['q3-1','q3-2','q3-3'],

        };

        let correct = 0;

        const total = correctAnswers.length;

        correctAnswers.forEach((ans, i) => {

            const qName = 'q' + (i + 1);

            const userAns = quizAnswers[qName];

            const allOpts = document.querySelectorAll[onclick*="selectOption(this, '${qName}'"]);

            allOpts.forEach(opt => {

                const optVal = opt.getAttribute('onclick').match(/'([a-d])'\)$/)[1];

                if (optVal === ans) opt.classList.add('correct');

                else if (optVal === userAns && userAns !== ans) opt.classList.add('wrong');

            });

            if (userAns === ans) correct++;

        });

        const pct = Math.round((correct / total) * 100);

        const resultEl = document.getElementById('result-' + quizId);

        resultEl.style.display = 'block';

        if (pct >= 70) {

            resultEl.className = 'quiz-result pass';

            resultEl.innerHTML = 🎉 ¡Excelente! Obtuviste ${correct}/${total} (${pct}%) — ¡APROBADO!;

            completeLesson(quizId);

        } else {

            resultEl.className = 'quiz-result fail';

            resultEl.innerHTML = ❌ Obtuviste ${correct}/${total} (${pct}%) — Necesitas 70% para aprobar. Revisa el material e intenta de nuevo.;

        }

    }
